# 🍽️ AI-Powered Meal Planner App

A smart meal planning application that generates personalized meal plans and recipes based on user dietary preferences using SQL, Python, and Large Language Models (LLMs).

## 🚀 Features

- 🔄 **Personalized Meal Plans**: Generates meal plans based on user-defined dietary restrictions and preferences.
- 🤖 **AI Recipe Generator**: Uses LLMs to create diverse and realistic recipes.
- 🗃️ **SQL Database Integration**: Stores user profiles, preferences, and meal history.
- 🖥️ **User-Friendly Interface**: Clean, intuitive UI for easy interaction and accessibility.

## 🛠️ Tech Stack

- **Frontend**: Streamlit 
- **Backend**: Python
- **Database**: MySQL
- **AI Integration**: ChatGroq 


## 🧠 How It Works

1. User signs up and sets dietary preferences (e.g., vegetarian, low-carb).
2. App stores preferences in a SQL database.
3. User requests a meal plan or recipe.
4. LLM generates meals based on input.
5. User receives a personalized, realistic meal plan and recipe.

## 🏁 Getting Started

### Prerequisites

- Python 3.8+
- MySQL 
- ChatGroq API Key (LLM)
- Required Python packages (`requirements.txt`)
